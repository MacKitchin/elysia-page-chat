# Extension package

If you are installing this for the first time, start at the **[repository README](../README.md)**. That guide covers clone, credentials, the proxy, and Chrome.

This folder is what Chrome must load (Developer mode → **Load unpacked**). `manifest.json` is here. Do not load the parent `elysia-page-chat` directory.

The proxy has to be running on your computer first, from the repository root:

```bash
npm run dev
```

Default origin: http://localhost:8788
