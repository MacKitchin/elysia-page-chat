# Extension package

**Load this folder** in Chrome (Developer mode → Load unpacked).

`manifest.json` is here. Do not load the parent `elysia-page-chat` directory.

The proxy must be running from the repository root:

```bash
npm run dev
```

Default origin: http://localhost:8788

Full setup, architecture, and security notes: [../README.md](../README.md) and [../docs](../docs).
